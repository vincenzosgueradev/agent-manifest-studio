# Screenshots

Images used by the root `README.md` (the marketplace page). Rules: `docs/marketplace-page-standard.md`.

## Rules

- **Sample data only.** Open a package generated by the helpers in `test/helpers/` or the sample logos in
  `sample-logos/`. Never a real tenant package, name, id or domain.
- PNG, the Power Platform ToolBox window with the tool in it (the host window is how the tool is really seen),
  width 1280 to 1920 px, zoom 100 %. A shot is not used if the host shows an environment name that is not sample data.
- One theme: the dark theme of Power Platform ToolBox, in `dark/`. The tool is checked in both themes by its tests
  and by hand (quickstart); the README shows one.
- Name: `NN-slug.png`. Do not rename once linked.
- Under 400 KB each. The folder is not part of the npm package (`files` is `dist` only).
- Retake a shot when the screen it shows changes (checklist item "Screenshot shows the current version").

## Adding a shot to the README

The marketplace reads the README as a raw file, where a relative image path does not resolve, so the links are
absolute and point to the `main` branch. A link works only after the image is pushed.

```markdown
![Package step with a sample agent loaded](https://raw.githubusercontent.com/vincenzosgueradev/agent-manifest-studio/main/docs/screenshots/dark/01-package.png)
```

Alt text says what is shown. Retake a shot when the screen it shows changes.
