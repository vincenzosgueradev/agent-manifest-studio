# Screenshots

Images used by the root `README.md` (the marketplace page). Rules: `docs/marketplace-page-standard.md`.

## Rules

- **Sample data only.** Open a package generated by the helpers in `test/helpers/` or the sample logos in
  `sample-logos/`. Never a real tenant package, name, id or domain.
- PNG, window of the tool only (no browser tabs, taskbar, bookmarks), width 1280 to 1600 px, zoom 100 %.
- One folder per theme: `light/` (the one the README shows) and `dark/` (the same shots again).
- Name: `NN-slug.png`, the same name in both folders. Do not rename once linked.
- Under 400 KB each. The folder is not part of the npm package (`files` is `dist` only).
- Retake a shot when the screen it shows changes (checklist item "Screenshot shows the current version").
