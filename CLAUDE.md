# Agent Manifest Studio - instructions for Claude

The project rules are in `.specify/memory/constitution.md`; read it before changing anything. This
tool works on a Teams app package file and never on an environment (Principle II).

## GitHub description

When a change touches what the tool does for the user, check the GitHub description and topics (Principle VI)
and propose the new text with the change. Apply it to GitHub only when the user says so.

## Skills

- Automatic (run without asking): `/custom-types`, `/custom-dedup`, `/custom-ampush` (read-only analysis).
- `/custom-commit` proposes a message and asks for confirmation. Commit only when the user asks.
- Only on the user's go-ahead: `/custom-cleanup`, `/custom-changelog`.
- Manual only, never by Claude: `/custom-publish` (publishes to npm). Never `git push` unless asked.

## Tests: nothing is finished without them (Testing Standard)

- After every code change: `npx tsc --noEmit`, `npm run build`, `npm test`. Report failures as they are.
- A new behaviour has a matrix of tests with an oracle written from the spec (no code shared with
  `src/`) and negative tests. Screen paths are tested by loading the real page in jsdom.
- A defect found by hand is reproduced by a failing test first; the test stays.
- After changing logic: `npm run test:mutation`. A surviving mutation is a missing test. Do not edit
  `src/` while it runs.
- Before proposing a release: `npm run test:full` and `npm run test:mutation` complete.
- Say what the tests do not cover (pixels as Teams draws them, Teams validation, the native save
  dialog) and keep it in the quickstart as a manual check with its recorded result.
- No real tenant data in fixtures: packages are generated by the helpers in `test/helpers/`.

## Specs

Every feature has `specs/NNN-name/` (spec, plan, research, data-model, quickstart, tasks,
checklist, contracts) and each requirement has code and a test in the traceability table of
`tasks.md`.

## UI rules

No emoji (CSS shapes and basic glyphs), no default checkboxes, colours from CSS custom properties,
both themes readable, no repeated values, explicit labels. The screen fills its container.
